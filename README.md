# MEETRA Mobile

MEETRA is an iPhone-first meeting recording and meeting intelligence PWA.

## GitHub Pages

This repository is configured to run from the project subpath `/MEETRA-Mobile/`.
Enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**.

Then open the published site in iPhone Safari and choose **Share → Add to Home Screen**.

> iOS browser limitation: keep the app in the foreground during important recordings. Privacy mode keeps browser speech recognition disabled.
